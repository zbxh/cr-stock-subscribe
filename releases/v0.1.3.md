# 补货订阅 0.1.3 测试版

修复代理商品库存判断、商家群地址编辑、会员通知筛选与邮件主题显示，优化商品搜索、补货去重索引和待发队列概览。

- 本地与代理商品统一使用 V10 已保存的商品总库存，不额外轮询上游。
- 商品关闭或删除后仍可改名、停用关联群地址；重新启用继续检查开放条件。
- 邮件详情不残留为普通通知列表的隐藏筛选，商品名称在主题和正文中正确显示。
- 商品下拉框使用本地搜索，新增商品与轮次联合索引。
- 发送频率旁显示待发情况、预计排空时间和过期提示，刷新保留设置草稿。

面向智简魔方 V10 业务系统 10.7 系列，已在 10.7.2、10.7.4 验证安装、通知和从 0.1.0／0.1.1／0.1.2 升级，保留配置与业务历史。

下载安装 `CrStockSubscribe-0.1.3.zip`，使用同名 `.zip.sha256` 校验。ZIP 顶层为 `cr_stock_subscribe/`，不包含测试脚本、站点配置或运行密钥。升级前请同时备份数据库和 Web 目录外的原密钥文件。
