# 0.1.0 测试版

补货订阅首个公开测试版，为智简魔方 V10 业务系统提供商品库存门槛订阅、补货与下架通知。

- 客户管理：分类搜索、多商品选择、一次提醒、持续订阅及个人 Webhook。
- 通知渠道：邮件、短信、企业微信、钉钉、通用 JSON；商家群与个人通知独立配置。
- 合并与控制：多商品合并、邮件／短信分别限速、短信额度、冷却和通知有效期。
- 后台管理：分类商品开放、需求统计、群发预览、通知记录、筛选搜索及后台诊断。
- 页面与模板：V10 原生后台组件、标准会员页与 CRA1、系统 Logo 邮件及原生模板管理。

适用环境：PHP 7.4 为运行基线；已验证 V10 10.7.2 与 10.7.4。详细范围见兼容说明。

安装请下载 **CrStockSubscribe-0.1.0.zip** 和对应 SHA256。ZIP 顶层为 `cr_stock_subscribe/`，放入 V10 的 `public/plugins/addon/` 后，通过后台正常安装并启用。GitHub 自动生成的 Source code 文件是仓库源码。

短信默认关闭，使用前需要配置 V10 原生发送接口及审核通过的模板；首次开放商品只记录库存基线，不立即通知已有库存。
