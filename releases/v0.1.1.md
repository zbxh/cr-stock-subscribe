# 0.1.1 测试版

修复主密钥与 Webhook 密文同库存放的问题，兼容从 0.1.0 正常升级。

- 主密钥保存到 Web 目录外的私有文件，权限为 0600；数据库、源码和安装包均不包含运行主密钥。
- 升级用新的随机主密钥重加密已有 Webhook，成功后删除库内旧密钥，保留订阅、待发任务、商家设置和自定义模板。
- 完善 JSON 凭据、访问令牌及 Bearer／Basic 认证的日志脱敏。
- Webhook 在发出请求前发生配置错误时明确记录失败；已经发送但无法确认的结果仍停止自动重发。
- 减少地址编辑的重复查询与解密，合并重复状态判断。

已验证 V10 10.7.2、10.7.4 的安装包、通知与迁移流程，PHP 运行基线为 7.4。其他版本的适用范围见兼容说明。

安装请下载 **CrStockSubscribe-0.1.1.zip** 和对应 SHA256，通过 V10 正常安装／升级。旧版无需卸载重装。升级前备份业务数据，升级后单独备份站点根目录（`public/` 的上一级）下 `data/cr_stock_subscribe/master.key`。迁移站点时须恢复同一密钥；自定义路径见配置指南。

历史 0.1.0 数据库备份仍可能含旧主密钥，应继续妥善保管。此次修复针对仅数据库泄露的防护，不改变既有备份。
