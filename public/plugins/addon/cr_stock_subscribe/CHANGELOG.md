# 更新日志

## 0.1.3 · 2026-11-11

### 问题修复

- 代理商品按 V10 已保存的商品总库存判断，移除误用库存回滚开关与固定过期时间造成的通知拦截；不增加上游轮询。
- 关联商品关闭或删除后，商家群地址仍能改名、停用；新增关联及重新启用继续检查商品开放条件。
- 邮件详情的单次事件筛选不再保存到普通列表状态，返回会员入口可以查看全部通知。
- 邮件主题保留商品名称原始文本，正文正确转义，兼顾自定义模板、短商品名和生成的商品清单。

### 优化

- 商品下拉框搜索使用已加载选项，减少重复请求。
- 增加商品与补货轮次联合索引，减少通知去重查询扫描。
- 发送频率旁增加待发概览、排空时间估算与过期风险提示，刷新队列不覆盖设置草稿。

### 回归

- 补充原生插件停启、多进程队列与邮件渲染回归；原有启停监听继续复用。

## 0.1.2 · 2026-11-06

### 问题修复

- 修复前台混选新商品与已有订阅时无法批量保存的问题；继续检查订阅版本，避免多页面修改互相覆盖。
- 父分类筛选包含其下级商品，并排除隐藏分类及其后代。
- 修改订阅导致商品移出已合并通知时，取消旧投递并重新合并有效商品，保留原通知明细与去重结果。

## 0.1.1 · 2026-11-06

### 安全修复

- 主密钥改存 Web 目录外的私有文件，安装包与数据库均不包含运行主密钥。
- 支持从 0.1.0 正常升级：用新密钥重加密已有 Webhook，事务完成后删除库内旧密钥，保留订阅、任务和自定义模板。
- 密钥丢失或迁移失败时保留原配置，不自动替换；补充密钥备份与恢复说明。
- 完善 JSON 签名密钥、访问令牌、Bearer／Basic 认证日志脱敏，统一接口异常日志处理。
- 区分 Webhook 请求发出前的配置失败与发出后的结果未知，保留诊断记录。

### 简化

- 地址编辑复用已解密结果，删除事务外重复的数量查询。
- 合并通知状态的重复判断，保留权限、并发复核及 Webhook 网络安全检查。

## 0.1.0 · 2026-11-03

首个公开测试版。

### 客户订阅

- 购物车公共入口、会员菜单、原生登录自动回跳。
- 分类搜索、多商品批量订阅、严格大于库存门槛、一次提醒与持续订阅。
- 个人 Webhook 管理、订阅修改退订及本人通知记录。

### 通知与管理

- 邮件、短信、企业微信、钉钉、通用 JSON；个人通知和商家群独立配置。
- 多商品按客户、渠道及地址合并，人工群发支持预览和逐商品去重。
- 商品隐藏或删除时发送下架通知，保留历史商品名称。
- 原生通知动作与模板，邮件使用系统 Logo、紧凑商品行及完整清单入口。
- 邮件与短信独立限速，短信预计费用、每日额度、冷却与发送前复核。
- 分类商品管理、需求统计、组合筛选、待处理明细、后台诊断与人工核对。

### 集成与兼容

- 独立 V10 插件，复用菜单、权限、钩子、分钟任务及发送接口。
- 后台复用通用组件，会员页适配标准主题和 CRA1。
- 停用／重装保留历史；调度延迟后继续有效提醒。
- 随包 DNS 运行库，无需额外服务或 Composer 命令。
