# 兼容说明

当前版本：**0.1.0 测试版**。

## V10 版本

| 环境 | 已验证范围 |
| --- | --- |
| V10 10.7.2、PHP 7.4 | 原始系统版本的数据库结构、插件安装、原生队列、库存与下架事件、多渠道合并、模板、限速、并发、标准主题管理员／会员及手机页面 |
| V10 10.7.4、PHP 7.4 | 原生安装升级、权限与菜单、库存和完整通知流程、管理员与会员页面、真实测试站自动邮件 |
| 其他 V10 10.7 版本 | 按相同原生插件、钩子、任务及通知接口设计；未逐个版本实测 |
| V10 其他主线版本及自定义主题 | 需要核对系统接口和主题公共入口，未作为已实测版本承诺 |

优先复用 V10 共用接口，不把 10.7.4 写成运行时的硬性版本锁。系统提供新的通知独立队列时继续使用插件原生任务接口；商品／订单钩子配合分钟扫描，不依赖一个特定商品编辑页面。运行文件全部在插件目录内，无需覆盖系统或主题。

## PHP 与数据库

- PHP 运行基线为 **7.4**。GitHub Actions 分别检查 PHP 7.4、8.1、8.2、8.3 的源码语法和安装包；整站是否能运行较新 PHP 还取决于使用者的 V10 版本、系统依赖和其他插件。
- 使用 V10 原有 MySQL/InnoDB 数据库连接及表前缀。迁移以新增表、字段和索引为主，系统升级事务提交后再执行 DDL。
- 需要 cURL、OpenSSL、mbstring；Webhook DNS 还需要 PHP 的 `stream_socket_client` 及服务器 DNS 的 UDP／TCP 出站能力。无需安装独立 DNS 服务或运行 Composer。
- 邮件与短信依赖 V10 已安装的发送接口、通知动作和模板。未启用接口、未审核短信模板及关闭的客户接收设置会明确显示原因。

## 主题与浏览器

- 后台：V10 通用框架、TDesign 及插件组件，支持独立后台目录。
- 会员：标准插件页面和 CRA1，桌面与手机视口经过流程检查。
- 购物车：公共区域唯一入口，针对标准页面及 CRA1 的公共容器适配；其他自定义主题仍可通过会员菜单进入，购物车公共入口需要对应主题保留可识别容器。
- 浏览器：当前桌面及移动版 Chrome、Edge、Firefox、Safari 等现代浏览器；不面向 IE 等缺少 Fetch／现代 JavaScript 的旧浏览器。自动浏览器流程在 Chromium 执行，未将全部浏览器列为逐项实测。
- 手机通过表格内横向滚动查看长列表。V10 后台壳本身的桌面最小宽度由系统决定，插件不修改系统壳。

## 安装包与升级

Release 安装包顶层为 `cr_stock_subscribe/`，V10 按 addon 模块解压到 `public/plugins/addon/` 后，可以直接识别 `CrStockSubscribe.php`。不增加 `public/`、仓库名或版本号外层目录。

初次安装、启用、停用、卸载重装及原生升级处理均保留独立业务历史；卸载不会自动删除历史数据。重新启用先建立库存基线，不重发旧提醒。后续 0.1.x 修复通过版本递增进入正常更新流程，历史发布文件保留。
